# Why no front end

An operator asks which range is filling up, reads the evidence and records a decision. The database holds that work. The coding agent runs the commands. Branded HTML shows the result without running a web server.

This gives you address planning, reservations, review evidence and handovers. It does not give you a clickable topology, a mobile field form, live discovery, offline team synchronisation or a drag-and-drop network designer. DNS, DHCP, device configuration and deployment remain separate systems.

Infrahub is a broader infrastructure platform and its Community edition is already open source. This project is for a team that wants a smaller address-planning workflow with its own review rules. Enterprise DNA builds shared screens, authenticated access, connections and operational controls into a custom version when those are needed.
